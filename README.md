# learn-github


ฟล์ README เป็นไฟล์ข้อความ (text file) ที่ใช้เป็นเอกสารประกอบโครงการหรือซอฟต์แวร์ โดยทั่วไปจะอธิบายรายละเอียดเกี่ยวกับโปรเจกต์, วิธีการใช้งาน, การติดตั้ง, ข้อกำหนด, และข้อมูลอื่น ๆ ที่เป็นประโยชน์สำหรับผู้ใช้งานหรือผู้พัฒนา. ไฟล์ README มักถูกเขียนด้วยภาษา Markdown หรือรูปแบบอื่น ๆ ที่สามารถอ่านได้ง่าย
